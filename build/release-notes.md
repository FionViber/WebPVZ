English and Simplified Chinese editions of Plants vs. Zombies: Game of the Year Edition.

## Play online

[Play the English edition](https://fionviber.github.io/WebPVZ/).

The Simplified Chinese edition is available as a download.

The browser editions require the page password. Desktop packages do not.

## Downloads

Filenames use `WebPVZ-1.0.0-LANGUAGE-PLATFORM-ARCHITECTURE.zip`.

- `EN`: English; `SC`: Simplified Chinese.
- Windows: `x64`.
- macOS: `arm64` for Apple silicon; `x64` for Intel.
- Linux: `x64` or `arm64`.
- `Web.zip`: the password-protected browser edition.

Extract each archive completely before opening it. Keep all accompanying files. See the repository README for launch instructions.

Desktop packages are recreated from the supplied files and verified file by file using SHA-256. macOS packages are unsigned and not notarised; macOS and Linux packages have not been tested on those systems. Archive checksums are supplied in `SHA256SUMS.txt`.
